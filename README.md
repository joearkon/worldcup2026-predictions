## 这是什么

2026 美加墨世界杯（48 队 / 104 场）期间，每天对当日比赛做赛前预测、输出独立报告页，赛后复盘。整站**纯静态**（HTML/CSS/JS，无后端、无构建），部署在 Cloudflare Pages。

- **不是投注工具**，是把"足球判断"结构化、可回溯、可验证的娱乐项目。
- 每场比分都给**主预测 + 次选**双锚，赛后按口径自动算命中率。

## 功能

- **📅 赛程时间轴**：小组赛全 72 场（北京时间），按日期分组、今日自动定位，已预测场次可点开报告。
- **🏆 晋级图（淘汰赛）**：独立的完整对阵树页 [`bracket.html`](bracket.html)（32 强 → 冠军，上下半区，大力神杯居中）+ 主页淘汰赛区的时间轴列表（按真实 2026 对阵模板，位置码 A1/B2/最佳第三名，逐轮锁定后填入真实球队）。**时间轴与晋级图两个入口都能点开预测报告**——报告存在 `matches`（按队名），经 `koReport()` 用 `ko.teams` 把位置码解析成队名后匹配；KO 行还显示「预测比分 + 晋级方」。
- **📊 单场预测报告**：五维评判 + 比分概率分布 + 关键先生 + 最终评判 + 盘口（欧盘/亚盘）+ 资料来源。**淘汰赛版**额外给：晋级方 + 120′比分(主/次) + 加时/点球走向(粗判) + 第⑦维 KO成色卡（五维/⑥维作历史沉淀权重参考）。
- **🏆 战绩看板**：拆**小组赛桶**（`比分命中率` + `胜负命中率`）与**淘汰赛桶**（`比分命中率`·含加时·点球不计 + `晋级命中率`·无平局 + 覆盖 x/32）+ 战绩流水。
- **🌍 小组积分榜**：按已完赛结果实时计算，每组前 2 标绿。
- **⚖ 赛后复盘**：差距拆解（判断误差 vs 临场变故），沉淀进复盘台账 + [方向全错总检讨](reports/世界杯复盘_方向全错总检讨.html) 专题页。
- **🌙/☀️ 暗/亮主题**切换（localStorage 记忆）。

## 预测方法论（简版）

- **五维框架**（定胜负与剧本）：① 阵容硬实力 ② 状态近况 ③ 历史交锋/魔咒 ④ 赛场因素 ⑤ **软性指标**（心气/韧性/动机/板凳——只放软性，不含盘口）。
- **球队画像**（数据中心 `team_profiles.md`）：每队记打法风格、防线成色（铁桶/会漏球）、门将、核心依赖、守成力——第二轮起决策重心从"盘口热门"挪到"对手成色"。
- **第⑥维·本届表现**（第 2 轮起）：球队踢过本届后，以**已兑现的过程**（xG/控球/失球方式，非单纯比分）读真实力，权重 ≥ ①；关键规则"虐菜=0"（赢鱼腩不算变强）。淘汰赛里五维 + ⑥维作为**历史沉淀的权重参考**带入。
- **第⑦维·KO成色**（淘汰赛专属）：点球史 / 大场抗压 / 连续作战板凳——**越往加时、点球拖，权重越高**（摩洛哥 2022 连点淘汰西葡 = clutch；西班牙传控、英格兰点球 = KO 窒息倾向）。**注**：报告维度线（五维①-⑤ + ⑥本届表现 + ⑦KO成色）与球队画像八维线是两套独立编号。
- **盘口是独立修正层**（不是维度）：五维搭骨架后，盘口做裁决——「退盘+砍让球+转小球」三连 = 机械下修；sharp 指向弱队不败 = 平局扶正为主；firm/没动 ≠ 利好。

**已沉淀的核心纪律**（详见 [`复盘台账.md`](复盘台账.md)，预测前必读）：
- **控得住 ≠ 攻得破**：别因控球/xG 高就押大胜（传控撞铁桶 = 低分闷局）。
- **净胜球收口**：默认往一球分差/平局收，只有"速度体能错配 + 对手愿对攻"才押 2 球净胜。
- **防线成色前置裁决**：先判对手是真铁桶还是会漏球，再决定深盘大热是反指还是该押大。
- **一场不改框架**：规则调整由用户拍板，台账只记录待样本。
- **淘汰赛 KO 专章**（台账新增）：没平局 → 改判「晋级方 + 走向（常规/加时/点球）」，#5 弱势方不败在 KO = 弱队能否拖加时/点球偷晋级；点球只粗判（不细测谁罚进）；小组赛末轮「留力/默契球/dead rubber」病根在 KO 消失 → R3 大轮换样本作废、不外推给 KO 评级；强强对话/早轮总进球档下调一档收口，强弱悬殊（会漏鱼腩）仍照旧往上够。
- **KO 位置码用项目自己回填的结果定**：项目分组字母 ≠ 真实世界（如荷兰项目 = F 组、真实 = G 组），直接套联网名单会让对阵树错乱。

## 目录结构

```
.
├── index.html              # 主页：时间轴 / 晋级图入口+KO时间轴 / 战绩 / 积分榜
├── bracket.html            # 淘汰赛完整对阵树（独立页）
├── data.js                 # 数据源：matches(预测+实际) / fixtures(72场) / groups / ko(淘汰赛)
├── theme.css, theme.js     # 暗/亮主题（全站共享）
├── assets/                 # 静态图（大力神杯等）
├── favicon.png …           # 站点图标 / 分享缩略图
├── reports/                # 每场预测报告 + 复盘报告（独立 HTML，带 OG 分享卡）
├── 复盘台账.md             # 【赛后】逐场复盘 + 跨场规律（预测前必读）
├── 临场追踪.md             # 【赛前】盘口移动 + 伤停首发记录
├── stats/                  # 数据中心：matches.json(真相源) + team_profiles.md(球队画像)
├── _headers                # Cloudflare Pages 缓存/安全头
└── deploy.sh               # 发布脚本（data.js 版本戳防缓存）
```

## 更新管道（本地 → GitHub → Cloudflare）

```bash
# 1. 本地改 data.js / reports/ / 台账 / stats/
# 2. 推 GitHub（所有更新都推，含 stats/）
git add -A && git commit -m "..." && git push origin main
# 3. 发 Cloudflare
bash deploy.sh
```

> `deploy.sh` 发 index/bracket/data/theme/reports/assets/图标；**不发** `复盘台账.md`、`临场追踪.md`、`stats/`（只靠 GitHub 留存）。
