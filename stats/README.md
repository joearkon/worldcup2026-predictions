# 世界杯预测 · 数据中心(stats/)

把每场赛后的技术统计沉淀下来,为**再次预测同一支球队**做数据补充。样本越多,画像越准。

## 两层结构
| 文件 | 角色 | 谁读 |
|------|------|------|
| `matches.json` | **真相源**:每场硬数据(比分/进球/控球/射正/xG/缺阵/我方预测对错) | 机器/聚合用 |
| `team_profiles.md` | **定性层**:每队 评分(进攻/防守1-10主观) + 主帅 + 画像 + 下轮注意点 | 预测前先读这里 |

## 铁律
1. **不编造**:高阶数据(控球/射正/xG)只录可核实的,未知填 `null` 并在 `_gaps` 标注。编数比缺数更糟。
2. **样本少=倾向非定论**:每队标已踢场次,1场只当先验。
3. **赛后即录**:每场终场→ matches.json 加一条 + team_profiles.md 更新涉及两队。

## 录入流程(每场赛后)
1. 抓终场比分、进球(人/时间/类型)、控球/射正/角球/xG(能查到的)、赛前重大缺阵。
2. 在 `matches.json` 的 `matches` 数组追加一条(字段见文件内 `_fields`)。
3. 填 `our_pred.status`(exact/alt/direction/miss)+ `tags` + `lesson`。
4. 更新 `team_profiles.md` 两队的"数据"行 + "画像/下轮注意"。
5. 与复盘台账(`../复盘台账.md`)联动:台账记"信号验证/规律",这里记"球队数据/画像"。

## 注意
- 本目录**不参与部署**(`deploy.sh` 只发 index/data/theme/reports),是本地数据资产,不公开。
- 与 `../data.js`(主页展示用预测记录)互补:data.js 给访客看,stats/ 给预测引擎(我)用。
